    Running Benchmarks¶

    Latency Test¶

    # Install
pip install locust

# Run
locust -f benchmarks/load_test.py \
  --host https://YOUR_URL \
  --users 10 \
  --spawn-rate 1 \
  --run-time 5m

    Accuracy Test¶

    python tools/run.py --pipeline evaluating \
  --config configs/evaluating.yaml
